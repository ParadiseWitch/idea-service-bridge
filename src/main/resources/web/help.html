查询状态

GET /v1/status 返回项目、配置和最新运行实例 ID。

点击查询状态。

提交更新或重启任务

先查询状态并选择目标，再检查 JSON。只有点击“提交任务”才会执行修改操作。

尚未提交任务。

202 表示已接收，继续查询直到 SUCCEEDED / FAILED。同项目任务冲突返回 409；编译或热替换失败不会自动重启。构建完成后请访问业务页面确认生效。
